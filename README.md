# 🛡️ Cowrie Honeypot Security Dashboard

An interactive cybersecurity dashboard built using
Cowrie, Python, Streamlit, Pandas, and Plotly.

## Features
- SSH honeypot monitoring
- SSH login attempt analysis
- Attacker IP tracking
- Command execution analysis
- Interactive security visualizations
- Custom vintage-inspired dashboard design

## Technologies
- Kali Linux
- Cowrie Honeypot
- Python
- Streamlit
- Pandas
- Plotly

## Run the Dashboard

Install dependencies:

pip install streamlit pandas plotly

Start the dashboard:

streamlit run dashboard.py

## Security

For educational and authorized security research only.
Do not publish captured passwords or private honeypot logs.
